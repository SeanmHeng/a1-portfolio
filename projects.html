The sites I work on

Two event-calendar websites for furry communities, what I contribute to each, and how they work.

Project 01

SoCalFurs

The website for the Southern California furry community. Behind it sits a production calendar automation platform used by 3,000+ people daily, which pulls community announcements from Telegram and publishes them as structured events.

Role
Full stack developer on a team
Tools
Python, Telethon, Gemini API, PostgreSQL, Google Calendar API, React, TypeScript, Node.js, Drizzle
Since
March 2026
  • Replaced polling-based Telegram checks with an event-driven Telethon workflow, so the platform responds faster and wastes less processing.
  • Built an ETL-style pipeline that uses the Gemini API to turn unstructured announcements into validated JSON, then loads it into PostgreSQL.
  • Sped up duplicate-event detection in Google Calendar by querying only the relevant date range, which also avoids API pagination limits.
  • Built a React, TypeScript and Node interface where organizers create, view and manage events.

Project 02

LocalFurry

A furry event calendar that gathers public event listings into one calendar per city, so people can find meetups, raves and other events near them.

Role
Works under the lead developer: Telegram adapter, city agents and dedup logic
Tools
Python, Telegram, autonomous agents
Since
September 2026
  • Building a Python adapter that connects Telegram to the site’s event calendar.
  • Managing autonomous agents that each look after the listings for one city.
  • Working on the dedup logic that keeps the same event from showing up twice when it is posted in more than one place.
